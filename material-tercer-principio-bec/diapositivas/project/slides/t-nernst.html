Enunciados de Nernst y Planck

Nernst (1906)

En todo proceso isotérmico reversible entre estados de equilibrio de un sistema condensado, la variación de entropía tiende a cero.

lím ΔS = 0 cuando T → 0

Planck (1912)

La entropía de todo cristal perfecto tiende a cero cuando la temperatura tiende a cero.

lím S = 0 cuando T → 0

Excepción: el hielo común conserva una entropía residual de unos 3.4 J/(mol·K), igual a R ln(3/2), porque sus protones se pueden ordenar de varias formas. Por eso Planck habla de cristal perfecto.

Nernst mide la variación de entropía; Planck fija el valor de S en el cero absoluto.
